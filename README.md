# Galata / گالاتا

نسخه اولیه قابل نصب برای تست منطق اصلی برنامه مدیریت کسب‌وکار آفلاین.

## امکانات نسخه 0.1.0
- ثبت‌نام و ورود محلی مالک
- داشبورد مالی
- مدیریت مشتری‌ها
- مدیریت کالا و خدمات
- فروش چندقلمی و ثبت فاکتور
- افزایش بدهی مشتری بعد از فروش
- تسویه کامل یا جزئی
- صورت‌حساب و گردش حساب مشتری
- یادآورها
- ثبت هزینه
- رابط فارسی و RTL
- دیتابیس SQLite داخلی

این نسخه برای بالا آوردن سریع پروژه و تست روی گوشی است. بعد از تأیید جریان‌ها، ظاهر برنامه مطابق طراحی و فلوچارت پروژه تکمیل می‌شود.
